# API Projekty
Tyto projekty slouží jako procvičení na přijímání API a následně je zobrazit na webu.

## Funkce stránky
Na této stránce se nacházejí následující API projekty:
- Pokemon Generator
- Crypto Dashboard

### Pokemon Generator
Stránka má za úkol si vybrat náhodného pokemona při načtení a následně zobrazit pokemona s designem na stránce.
Funkce stránky:
- Po načtení stránky se vybere náhodný pokemon
- Po stisknutí tlačítka se taktéž vybere náhodný pokemon

### Crypto Dashboard (wip)
Stránka má za úkol načíst data nejpopulárnějších krypt, uživatel si taktéž může vybrat měnu (CZK, EUR, USD).
Funkce stránky:
- Po načtení stránky se zobrazí informace od 5 nejpopulárnějších krypt
- Uživatel si může vybrat měnu a poté se stránka obnoví s nově načtenými daty
